KWstore — kk new fashion website (DESIGN PREVIEW)
=================================================

Ye website ka front-end (jo dikhta hai) hai — app jaisa smart design,
cream + orange theme, sample products ke saath. Database ki abhi zaroorat NAHI.

CHALANE KA TAREEQA (bohot aasan):
1. Is folder (KWstore) ko Desktop par rakhein.
2. Is folder ko address bar mein "cmd" likh kar khol lein (black window).
3. Ye 2 command, ek ek karke:

   npm install
   (2-3 minute intezar karein)

   npm run dev

4. Chrome mein kholein:  http://localhost:3000

DEKHNE KE LIYE:
- Home page (search app-jaisa orange border, banner, products grid)
- Kisi product par click -> poora product page (gallery + order form)
- Order form mein Payment: COD pehle, phir JazzCash / Easypaisa / Bank
- Confirm order -> success page

NOTE:
- Photos abhi sample (random) hain. Asli products/photos aur admin/orders
  agle step mein database (Neon) se jodenge.
